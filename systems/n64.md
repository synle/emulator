# Nintendo 64

- Released: 1996
- Common ROM extensions: `.z64` (big-endian, preferred), `.n64`, `.v64`
- BIOS required: **no** (64DD games need `64DD_IPL.bin`)

## Prerequisites

### Firmware / BIOS

- **BIOS** — not required for cartridge games.
- **64DD IPL** — required only for the Japan-only 64DD disk drive peripheral (very few titles).

| File           | For             | Required? |
| -------------- | --------------- | --------- |
| `64DD_IPL.bin` | 64DD disk games | Optional  |

### System requirements

**Desktop (Windows / macOS / Linux)**

- Minimum: 2015-era Intel i3 / Ryzen 3, integrated graphics, 4 GB RAM.
- Recommended: i5 / Ryzen 5 + any discrete GPU for 4× upscaling + ParaLLEl-RDP accuracy.

**Android**

- Minimum: Snapdragon 660 / Dimensity 700, 4 GB RAM.
- ✅ **S24 Ultra** (SD 8 Gen 3) — effortless at 4× upscale.
- ✅ **Z Fold 5** (SD 8 Gen 2) — effortless.
- ✅ **Tab S9 Ultra** (SD 8 Gen 2, 14.6" OLED) — effortless; the large screen is great for N64.

**iOS / iPadOS**

- Minimum: A12 Bionic (iPhone XS / iPad mini 5).
- ✅ **iPad Pro 12.9" M1** — 4× upscale with ParaLLEl-RDP is smooth.

**Handhelds (SteamOS / Windows handhelds)**

- ✅ **Steam Deck** — Mupen64Plus-Next at 3–4× upscale handles the library well; ParaLLEl-RDP for tricky titles (Majora's Mask).
- ✅ **Legion Go** — comfortably runs ParaLLEl-RDP at 4× upscale.

## Recommended emulators

| Emulator                      | Type          | Notes                                              |
| ----------------------------- | ------------- | -------------------------------------------------- |
| **Mupen64Plus-Next**          | libretro core | Default on Steam Deck, RetroArch                   |
| **ParaLLEl N64**              | libretro core | Accurate GPU via Vulkan; fixes many graphical bugs |
| **simple64**                  | standalone    | Highly accurate; Windows/Linux                     |
| **Rosalie's Mupen GUI (RMG)** | standalone    | Windows/Linux GUI around mupen64plus               |
| **Ares**                      | standalone    | Multi-system; accurate N64                         |

Accuracy ranking (rough): Ares ≈ simple64 > ParaLLEl > Mupen64Plus-Next.

## Per-platform install

### Android

- RetroArch → Core Downloader → **Mupen64Plus-Next** (requires GL ES 3.0+).
- Standalone: **M64Plus FZ** (Play Store, free; Pro for extra plugins).

### iOS

- RetroArch → **Mupen64Plus-Next**. Performance varies — iPhone 12+ recommended.
- **Provenance** also supports N64 on newer iPads.

### macOS

- RetroArch + Mupen64Plus-Next (Metal backend works on Apple Silicon).
- **OpenEmu** wraps mupen64plus.
- Ares: `brew install --cask ares`.

### Windows

- RetroArch + Mupen64Plus-Next or ParaLLEl N64.
- **Rosalie's Mupen GUI**: https://github.com/Rosalie241/RMG — clean GUI, good defaults.
- **simple64**: https://simple64.github.io.
- **Ares**: https://ares-emu.net.

### Linux (Ubuntu)

```bash
sudo apt install retroarch libretro-mupen64plus-nx libretro-parallel-n64

# Standalone
flatpak install flathub io.github.simple64.simple64
flatpak install flathub dev.ares.ares
```

## Per-frontend setup

### RetroArch

1. Core: **Mupen64Plus-Next** (default) or **ParaLLEl N64** (Vulkan, accurate).
2. GFX plugin: `Options → GFX Plugin` → GLideN64 (balanced) or Angrylion (software, slow but exact).
3. Controller: N64 pak slots are configured under `Quick Menu → Controls` (Memory Pak vs. Rumble Pak).

### EmuDeck

- Default: RetroArch + Mupen64Plus-Next. Optional standalone **simple64** if chosen in Custom install.
- ROM folder: `~/Emulation/roms/n64/`
- High-res textures: drop packs in `~/Emulation/storage/mupen64plus/hires_texture/<rom-name>/`.

### RetroDeck

- Default: RetroArch + Mupen64Plus-Next.
- ROM folder: `~/retrodeck/roms/n64/`

## Controller notes

- N64's C-buttons map to the **right analog stick** by default in all cores — this is usually what you want.
- Z-trigger conventionally maps to L2 on modern pads.

## Tips

- `.z64` is the canonical format. Convert `.v64`/`.n64` with `tool64` or just let the emulator byteswap on load.
- Some games (Perfect Dark, Conker) require specific video plugin settings; consult `https://n64brew.dev/wiki/Emulators` for quirks.
- Widescreen hacks: enable under Mupen64Plus-Next options for a handful of supported games.
